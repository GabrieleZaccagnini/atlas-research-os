# Atlas — Starter identity v1

Atlas is a crypto research and market intelligence workspace.

**Map the Market. Find the Signal. Build Conviction.**

## Identity
An orbital A represents mapping the market; the cyan star represents finding a signal. Use uppercase ATLAS in the visual wordmark and Atlas in prose. Tone: clear, calm, evidence-led. Describe observations and uncertainty plainly; avoid guaranteed-return language.

## Assets
- `public/brand/atlas-lockup-dark-v1.png`: symbol and wordmark together.
- `public/brand/atlas-symbol-dark-v1.png`: square symbol for avatars and large app tiles.
- `public/brand/atlas-wordmark-dark-v1.png`: lettering alone.
- `public/brand/atlas-brand-board-v1.png`: visual identity reference.

These are starter raster PNG assets with dark backgrounds, generated using the built-in image-generation tool. They are not transparent files or vector masters. Small variations exist between generated specimens. Use the horizontal lockup as the primary reference. A simplified vector master and favicon should be made before small-size production rollout.

## Typography
Use existing Inter for interface headings and body text, with JetBrains Mono for prices, timestamps and numeric data. The generated ATLAS lettering is custom artwork, not an installed font. Keep the tagline in sentence case.

## Usage
Keep clear space around the symbol and wordmark at least the height of the letter T's top bar. Preserve proportions. Place these dark assets on matching dark surfaces. Avoid added glow, shadows or busy chart backgrounds. Use the symbol alone where the full wordmark becomes unreadable. Evaluate at actual display size before adoption.
